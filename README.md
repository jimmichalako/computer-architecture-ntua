# NTUA ECE Computer Architecture Course

This repository showcases the projects and assignments I completed during the Computer Architecture course. Through this coursework, I gained hands-on experience in MIPS assembly programming, evaluating processor performance, and analyzing memory hierarchies.

## Assignments

### Assignment 1: MIPS Assembly Programming
*Practical implementation of algorithms and machine learning concepts using low-level MIPS assembly.*

*   **Key Tasks:** 
    *   **Part A (Array Minimum):** Developed a `findmin` subroutine to find the minimum value in an integer array. Implemented stack frame management (prologue/epilogue) for saving registers, pointer arithmetic for array traversal, and loop branching.
    *   **Part B (Neuron Perceptron):** Simulated a single-neuron forward pass. Computed the dot product of a weight array and an input array, added a bias value, and applied a ReLU (Rectified Linear Unit) activation function to the accumulator sum.
*   **Tech Stack:** MIPS Assembly, MARS MIPS Simulator.

### Assignment 2: Datapath & Pipelining
*Processor performance analysis and instruction execution.*

*   **Key Tasks:** Processor cycle evaluations, datapath analysis, and pipelining constraints.
*   **Tech Stack:** MIPS Architecture Analysis, Document Reports.

### Assignment 3: Memory Hierarchy & Caches
*In-depth analysis of memory systems, cache architectures, and performance optimization.*

*   **Key Tasks:** 
    *   **Part A:** Calculated the required hit rate of a Victim Cache to achieve a memory access speedup of ≥ 1.25. Factored in an L1 miss penalty of 49 cycles, an L1 hit rate of 94.6%, and analyzed conflict misses representing 37.5% of total misses.
    *   **Part B:** Derived architecture specifications for a 32-bit processor featuring a 512B direct-mapped, write-allocate L1 cache with a 64-byte block size. Extracted parameters such as block size, block offset, and physical address bits.
*   **Tech Stack:** Mathematical Derivations, Cache Memory Mathematics.

## Technologies Used

*   **Languages:** MIPS Assembly
*   **Core Concepts:** Instruction Set Architectures (ISA), Stack Pointers, Pipelining, Cache Mapping, Memory Hierarchy
*   **Environments:** Document Reports (PDF)
